Принципы ООП
1) Абстрация
2) Инкапсуляция
3) Наследование
4) Полиморфизм

---
Ключевые слова

extends - наследует класс
super - конструктор материнского класса в дочернем - обязателен! и обязателен первой строкой! чтобы инициализировать в дочернем поля материнского
implements - наследует интерфейс (без полей только методы, поэтому супер и не нужен)

---
Интерфейс
фактически контракт с перечислением методов которые обязательно должны реализовать наследники

Обычнно реализация методов интерфейса в наследниках но!:
- можно static
принадлежит интерфейсу (и не требует обьекта для использования), иммутабелен
- можно default
принадлежит обьекту-наследнику, мутабелен переопределением
